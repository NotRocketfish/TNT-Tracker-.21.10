# TNT Tracker

A Fabric mod for Minecraft 1.20.4 that records TNT flight paths, counts destroyed blocks per shot, and includes a replay system.

## Features
- Trail recording (dots/lines) with customizable group distance
- Shot summary: total blocks destroyed per cannon shot
- Safe Mode (no damage, no block destruction)
- Replay system with speed control and scrubbing
- Remote Trigger item
- Supports 23 languages

## Installation
Requires Fabric API. Drop the jar in your mods folder.
